# 常见问题

## 订单相关

如果您下单后发现填错了收货地址或联系电话，在订单状态为"待发货"时，您可以自行在订单详情页修改收货信息。一旦订单进入"已发货"状态，收货地址将无法直接修改，您需要联系客服尝试拦截包裹或协调物流公司进行转寄。关于订单取消，待付款订单会在二十四小时内自动取消，已付款但未发货的订单可以随时申请取消并全额退款。如果您发现收到的商品与订单不符，例如颜色、尺码或型号有误，请拍照留存并在四十八小时内联系客服，我们会为您安排换货或退款并承担全部运费。

## 账户与安全

如果您忘记了登录密码，可以在登录页面点击"忘记密码"，通过绑定的手机号或邮箱接收验证码后重置密码。为了账户安全，我们建议您定期更换密码并使用字母、数字和特殊字符的组合。如果发现账户有异常登录行为，请立即修改密码并在"安全中心"中检查最近的登录记录，必要时可以联系客服冻结账户。ShopEase 承诺不会以任何理由索要您的密码或验证码，请警惕任何冒充平台客服的诈骗行为。

## 优惠券与积分

优惠券通常通过平台活动、签到或会员等级权益发放，每张优惠券都有明确的使用门槛和有效期，您可以在"我的优惠券"页面查看详情。优惠券的面额不能超过订单金额，差额部分不设找零。积分则根据消费金额按比例累积，每消费一元可获得一个积分，一百积分可抵扣一元。积分有效期为自获得之日起一年，过期积分将自动清零，请在有效期内及时使用。
