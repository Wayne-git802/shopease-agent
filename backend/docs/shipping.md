# 配送政策

## 配送范围与时效

ShopEase 目前的配送网络覆盖全国绝大部分省市区县，包括一线城市、二三线城市以及部分乡镇地区。对于新疆、西藏、青海等偏远地区的部分县城，我们会根据实际物流情况评估是否可达，下单时系统会自动判断您的收货地址是否在配送范围内。通常情况下，一线城市及省会城市的订单在下单后一到两个工作日内即可送达，二三线城市需要两到四个工作日，而偏远地区则可能需要五到七个工作日。如果您选择的是顺丰速运等加急配送服务，大部分城市均可实现次日达或隔日达。

## 配送费用

订单金额满九十九元即可享受全国包邮服务，不满九十九元的订单将根据收货地址和商品重量收取八到十五元不等的配送费用。对于大件商品，如家电、家具等，配送费用会单独计算，请在下单时查看系统给出的最终运费报价。加急配送服务的费用由第三方物流公司根据时效和距离定价，一般在十五到三十元之间。节假日期间，由于物流资源紧张，部分地区的配送时效可能会有两到三天的延迟，同时加急配送的费用也会相应上浮。

## 签收与验收

我们强烈建议您在收到包裹时当场开箱验货。如果发现外包装有明显破损、变形或被挤压的痕迹，您有权拒绝签收并立即联系 ShopEase 客服。对于高价值商品，务必在签收后二十四小时内仔细检查商品是否完好，如有问题请及时拍照留证并与客服沟通。超过签收后四十八小时未提出异议的，我们将默认商品完好交付，后续的损坏申诉可能无法得到支持。
