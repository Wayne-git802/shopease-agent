# 退换货政策

## 退货条件

在 ShopEase 平台购买的商品，自签收之日起七天内，如果商品保持完好且未经使用，您可以申请无理由退货。所谓"完好"，指的是商品及其配件、赠品、包装和标签均保持原状，不影响我们的二次销售。需要特别说明的是，生鲜食品、个人护理用品、定制商品以及数字商品一经激活或使用，将不再支持退换货服务。如果您购买的是电子产品，请在确认商品存在质量问题后再进行拆封，拆封后的电子产品若无质量问题同样无法办理退货。

## 退款时效

我们收到您退回的商品后，会在三个工作日内完成质量检验。检验通过后，退款将在五个工作日内原路返还至您的支付账户。如果您使用优惠券或积分进行了部分抵扣，优惠券部分将按使用比例退还至您的账户，积分部分将全额退回。请注意，退款到账的具体时间还取决于您所选择的支付渠道，银行卡退款通常需要三到七个工作日，而微信支付和支付宝通常在两个工作日内即可到账。

## 退货运费

因商品质量问题导致的退货，来回运费均由 ShopEase 承担。您可以选择自行寄回并保留运费凭证，我们在收到退货后会为您报销运费，或者联系我们的在线客服申请上门取件服务。若属于无理由退货，退回的运费需要由您自行承担，我们建议您选择有跟踪记录的快递方式，以便随时查看物流状态。如果商品在运输途中发生损坏，您需要在签收时当场验货并向快递公司提出索赔，同时通知我们的客服人员协助处理。
